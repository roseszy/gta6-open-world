Solmar Heat is a top-down open-world crime game set in the sun-soaked streets of Solmar City: steal cars, outrun the police, run story missions for the fixer Mara Voss, and make the city pay — all in your browser, no downloads.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play with keyboard and mouse.
